*restful.nvim* Discover and query server API endpoints.

==============================================================================
COMMANDS                                                             *restful-commands*

:Restful [METHOD] [query]
                        Open the endpoint picker. METHOD is optional and may
                        be GET, POST, PUT, PATCH, DELETE, HEAD, OPTIONS,
                        TRACE, CONNECT, ANY, or ALL.

:RestfulRefresh[!]     Refresh the current project index. ! forces a new scan.
:RestfulDiagnostics     Put current index diagnostics in the quickfix list.
:RestfulFrameworks      List detected providers and endpoint counts.
:checkhealth restful    Inspect runtime dependencies and loaded providers.

==============================================================================
CONFIGURATION                                                         *restful-setup*

require("restful").setup({
  scan = { exclude = { "node_modules" }, parse_budget_ms = 6 },
  request = {
    base_url_variable = "API_BASE_URL",
    fallback_base_url = "http://localhost:8080",
    confirm_unsafe_methods = true,
  },
})

==============================================================================
API                                                                  *restful-api*

require("restful").open(opts)
require("restful").refresh(opts)
require("restful").diagnostics()
require("restful").frameworks()
require("restful").register_provider(provider)

==============================================================================
PROVIDERS                                                         *restful-provider*

A provider must expose an id and languages. It may implement detect(context),
parse(text, context), extract(context, file, tree), and resolve(context,
fragments, graph). Normalized endpoints contain methods, path, handler,
declaration, parameters, framework, and language.
